# The storytime bar

A storytime talk is remembered as a **world**, not a deck. The audience follows
someone or something through one place while the speaker talks, and the picture
changes as the explanation advances. These principles hold in every style, from
pixel art to a board-level annual-report look. Style changes the costume, not
the skeleton.

## The template test

Before you keep any state, ask: *could this pass for an ordinary template
slide with a picture added?* (Title at top, subtitle, boxes with numbers,
footer.) If yes, redesign it. This applies to serious rooms too: a quiet,
precise world is still a world.

## The ten elements

1. **One committed world.** One palette, one display typeface plus one
   workhorse face, one drawing logic, one scale. Acts may change *location*
   (the street, the depot, the control room), never style.
2. **Someone to follow.** A recurring original character who reacts (confused,
   alarmed, relieved, pointing) or, in serious rooms, an **object hero**: the
   order, the sample, the packet, the dollar. The audience tracks it through the
   mechanism. Give it 4–8 poses or states.
3. **One headline tag per state.** About six words or fewer, in one fixed
   component and position. It compresses the spoken beat; it never transcribes
   it. In leadership rooms the tag is answer-first ("holding cuts waits 44%"),
   not a topic label ("Results").
4. **A persistent mechanism scaffold.** The core mechanism is drawn once and
   stays on screen across many clicks: a route, a pipeline, a next-word bar
   list, a body, a machine, a map. **Each click changes one nameable thing.**
   Return to the same scaffold later with a new input; the second explanation is
   then almost free.
5. **Metaphors drawn, then labelled.** A metaphor that can be drawn as part of
   the scene is shown first, then each element gets a label, one per click
   (`FORK = HIGH ENTROPY`, `LANTERN = OUR SEARCH`). A metaphor that only works
   in words is rejected.
6. **Data drawn in the world, exactly.** Grids of tiny people, beads, bars on
   a chalkboard, a dial on a dashboard: styled, but with the true values, units,
   denominators, and uncertainty legible. A giant single number may hold the
   screen alone.
7. **Honest small print, always visible.** A stamp (`ILLUSTRATIVE`,
   `SCHEMATIC`, `PAPER RESULT`, `OUR DATA`, `PROJECTION`) in one corner and a
   source line in another, on every evidence state. Spectacle never removes the
   qualification. A limitation that changes the conclusion is on the slide,
   not only in the notes.
8. **An audience moment.** In the first two minutes: a guess, a vote, a
   prediction, a "which would you pick?". The reveal confirms or breaks it.
9. **Act cards and bookends.** Each act opens with a short card ("PART II ·
   Following the footprints"). The opening scene returns at the end, changed by
   what the talk established.
10. **Pace.** The picture changes roughly every 5–15 seconds of speech (slower
    in leadership rooms; see `intake.md`). Long holds only on a big number, a
    card, or a question to the room.

## What changes between rooms (and what never does)

| Element | Playful room | Serious room |
|---|---|---|
| Character | Mascot with expressions | Object hero, or a quiet figure with posture only |
| Tag | Wry, short ("then it locks in") | Answer-first, exact ("2 of 9 lines cause 61% of delay") |
| Motion | Bouncy reactions, character travel | Calm morphs, slow camera, no bounce |
| Metaphor | Literal and fun (a forest fork) | Literal and dignified (a valve, a gate, a ledger) |
| Text density | Tag + labels | Tag + labels + exact figures + footnote line |
| **Never changes** | the persistent scaffold, one change per click, exact numbers, visible stamps and sources, the bookend |

## Anti-patterns and their fixes

| You see | Fix |
|---|---|
| Title + bullets over a picture | Move the sentences to notes; keep one tag; draw the idea |
| A KPI card floating on a gradient | Put the number on an object in the world (a sign, a dial, a chalkboard, a ticket) |
| The diagram is redrawn from scratch every click | Give it stable ids; change one part per state |
| Generic boxes and arrows | Give the process a place and a unit you can track (a bus, a parcel, a token) |
| A character that only decorates | Make it react to the beat, point at the change, or *be* the unit |
| Pretty but the number is tiny | One number per state at ≥ 120 px; label and unit ≥ 28 px |
| Ten things animate at once | Split into states; one nameable change per click |
| A caveat only in the notes | Put a short qualifier beside the claim and in the stamp |
| Decorative motion loops | Keep only tiny idle life (blink, flicker); honour reduced motion |
| The style is chosen for one gorgeous hero frame | Test it on the hardest data-heavy beat too |

## The contact-sheet review

Render every state and view them together as a contact sheet. Then check:

- Every state is a full-bleed scene in the same world; none reads as a template.
- No state has a bullet list or more than one tag plus labels and small print.
- The character or object hero appears throughout and reacts to what is said.
- The scaffold persists across clicks and returns at least once.
- Each act opens with a card; the ending visibly resolves the opening scene.
- Squint test: the most important thing on each state is the most visible.
- Back-row test: at 25% size, the tag and the key number are still readable.
- Story test: without narration, the sequence still tells the gist.

Revise the weakest three states before calling the deck done.
